ACM2004D-FLW-FBW-IICの端子の並び

画面を上に向けて、７つの端子が奥の方にくるようにして左から
  1. Vss、電源マイナス
  2. Vdd、電源プラス(5V)
  3. V0、よくわかんない
  4. SDA、データ線
  5. SCL、クロック線
  6. BL+、バックライト プラス5V
  7. BL-、バックライト マイナス

ラズパイpicoのなかみ

main.py 
from machine import I2C,Pin
import machine
from ACM2004DLCD import RW1063LCD
import time

#LCD i2C Setting
sda = machine.Pin(2)
scl = machine.Pin(3)
i2c_lcd = I2C(1,scl=scl,sda=sda,freq=400000)
lcd = RW1063LCD(i2c_lcd, addr=0x3F)
#lcd = I2cLcd(i2c_lcd, 0x3f, 4, 20)
lcd.clear()

while True:
    lcd.move_to(0,0)
    lcd.putstr("ミロストル ケッシャ")
    lcd.move_to(0,1)
    lcd.putstr("アイウエオカキクケコサシスセソタチツテト")
    lcd.move_to(0,2)
    lcd.putstr("The Milostol Society")
    lcd.move_to(0,3)
    lcd.putstr("ABCDEFGHIJklmnopqrst")
    time.sleep(2)
    lcd.clear()
    time.sleep(0.5)

解説

lcd.move_to()について

カーソルを動かす関数。第一引数は列、第二は行を指定する。0,0で、1行目1列目という意味。

putstr()

文字列を表示させる。行に文字列が収まらないと、変に改行されてしまう。使える文字はACM2004DLCD.pyの中にでっかい辞書の変数があるからそれ参照。

clear()

表示している文字をクリア
